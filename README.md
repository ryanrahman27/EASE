# EASE

Cross-embodiment robot control research. The [technical report](examples/ease_fm/TECHNICAL_REPORT.md) tracks the experiments, methods and outcomes.

The iteration history is a retrospective import. Commits labeled Archive contain saved protocols, reports, report excerpts or available source snapshots associated with each documented experiment. The import date is the commit date. The workspace snapshot includes the current EASE modules and tests. Some experiments depend on earlier generated outputs, model weights, MuJoCo assets and a CUDA-enabled Python environment. Raw simulation outputs and checkpoints are stored separately.
